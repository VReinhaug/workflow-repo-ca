# Workflow repo for the CA

## Description

This project is a course assignment for Front End development at Noroff for the course Workflow. It includes unit testing and end to end testing.

## Getting started

### Installing

It is easy for you to get this project started:

1. Clone the repository:

```bash
git clone git@github.com:VReinhaug/workflow-repo-ca
```

2. Install the dependencies:

```
npm install
```

### Required environment variables

TEST_USER_EMAIL
TEST_USER_PASSWORD

### Scripts

To run the app, run the following command:

```
npm run start
```

To run tests with Vitest:

```
npm run test:unit
```

To run tests with Playwright:

```
npm run test:e2e
```
